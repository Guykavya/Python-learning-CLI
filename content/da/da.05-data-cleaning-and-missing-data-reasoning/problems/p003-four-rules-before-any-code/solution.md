## Approach

The model answer in `answer.md` takes the three questions in order. The pattern is always the same: a rule exists
because the opposite habit makes the work **impossible to repeat, impossible to measure, or impossible to undo**.
Rate your answer against the checklist at the end of `answer.md`; you do not need the same words, only the same ideas.

## Complexity

Not applicable. The cost of these rules is a few lines of code per step; the cost of ignoring them is a result nobody
can trust or reproduce.

## Another way

Tell it as a story: next Monday the survey office sends a corrected file. With a script and a log, you run one command
and read the new log. With hand edits in Excel, you start again from nothing, and you cannot even remember what you did
the first time.
