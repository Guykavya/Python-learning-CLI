## Hint 1

Ask of each task: does a person watch it run, or does a machine? Will it be run once or many times? Does other code need to import it?

## Hint 2

```text
exploring, showing, one-off      -> notebook (fast feedback, shows output)
repeated, scheduled, reused      -> script / module (runs top to bottom, importable)
has tests                        -> module + pytest, never logic buried in cells
```
Then say what goes wrong if you pick the other tool.
