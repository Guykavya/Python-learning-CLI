## Hint 1

Imagine finding a name in an unsorted pile of 200000 cards. What must you do if the name is not in the pile?

## Hint 2

Multiply: how many lookups does the program make, and how many comparisons can each lookup take?

## Hint 3

For the set, think of a cupboard with numbered drawers, where a rule computed from the word itself tells you
which drawer it must be in. How many drawers do you open to check a word?
