## Approach

The model answer is in `answer.md`. The main habit is to decide the rules **before** the contest: time boxes, the skip rule, and the pre-submission check, because during a round tiredness and hope make bad decisions.

A plan that contains only wishes ("stay calm", "solve as many as possible") fails the checklist; times and triggers pass it.

## Complexity

Not applicable.

## Another way

Use a one-page card with the rules and read it aloud before the contest starts. Some people also set a timer for the time boxes.
