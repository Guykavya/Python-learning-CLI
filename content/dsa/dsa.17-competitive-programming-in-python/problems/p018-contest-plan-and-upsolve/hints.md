## Hint 1

Think about the order in which problems get solved: the contest board shows how many people solved each problem. Use it as information. What do you read first?

## Hint 2

Give every problem a **time box** (for example 25 minutes for an easy one) and a rule for what happens when it runs out. Decide the rules **before** the contest, because during it you will be tired and hopeful.

## Hint 3

For upsolving: take the first problem you could not solve, try again alone for a fixed time, then read the editorial, then **re-implement without looking**, and write down the idea in one sentence in a log.
