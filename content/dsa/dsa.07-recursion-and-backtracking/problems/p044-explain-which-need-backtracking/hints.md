## Hint 1

Look for the key word first: *list every / generate* (all answers must be produced), *count* (only a number), *largest / fewest* (an optimum), *check* (yes or no).

## Hint 2

For a "count" problem, ask: is the same situation (state) reached by many different paths? If so, remembering it pays (D). If every path is different, you must walk them (B).

## Hint 3

If `n` is 100,000, an exponential search is impossible: look for a single pass.
