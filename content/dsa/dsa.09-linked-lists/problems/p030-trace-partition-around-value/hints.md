## Hint 1

`3 < 5`, so `3` goes to small; big is still empty. `5 < 5` is false, so the first `5` goes to big. Each line shows both sides **after** the node was added.

## Hint 2

The order inside each side is the order of arrival. At the end, small `3 -> 2 -> 1` is followed by big `5 -> 8 -> 5 -> 10`.
