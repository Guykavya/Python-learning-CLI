# Plan before you code

Here is a problem. **Do not write a program for it.** This exercise is about the thinking you do
before you type any code.

> Read a whole number `n` (`1 <= n <= 10^6`). Count how many numbers from 1 to `n` have a
> digit sum that is divisible by 7, and print that count.

(The digit sum of 386 is 3 + 8 + 6 = 17.)

In `answer.md`, write:

1. **Restate** the problem in your own words. Say exactly what the input is and exactly what the output is.
2. **Work two examples by hand**: `n = 20` and `n = 70`. List the numbers that qualify and give the count for each.
3. **Write the plan** as numbered steps or pseudocode that a classmate could turn into Python without asking you anything.
4. **List edge cases** (the smallest `n`, the first `n` where the answer is not 0, anything easy to forget) and give the correct answer for each.
5. **Estimate the work** for `n = 10^6`: roughly how many basic steps will your plan take, and is that fast enough in Python?
   (A useful rule of thumb: Python does around 10 to 50 million simple steps per second.)

Aim for something you could hand to a teammate. Short, numbered, precise.
