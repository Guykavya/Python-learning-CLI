# Digit sum without strings

Read one integer `n` (it may be negative or zero) and print the sum of its digits.

**Rule:** do not convert the number to a string. Use arithmetic only.

| Input | Output |
|---|---|
| `1234` | `10` |
| `0` | `0` |
| `-905` | `14` |

Use `input()` without a prompt message.

Before coding, write in a comment: what does `n % 10` give, and what does `n // 10` do?
