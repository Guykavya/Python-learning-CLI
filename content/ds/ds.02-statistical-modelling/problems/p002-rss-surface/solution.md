## Walk-through

Line (0.0, 2.0): fitted 2, 4, 6, 8; gaps 0, -1, -1, -2; squares 0, 1, 1, 4; RSS = 6.00.

Line (0.5, 1.4): fitted 1.9, 3.3, 4.7, 6.1; gaps 0.1, -0.3, 0.3, -0.1; squares 0.01, 0.09, 0.09, 0.01; RSS = 0.20.

Line (1.0, 1.0): fitted 2, 3, 4, 5; gaps 0, 0, 1, 1; squares 0, 0, 1, 1; RSS = 2.00.

The smallest is the second line, which is the least-squares line (slope 7/5 = 1.4, intercept 4 - 1.4 * 2.5 = 0.5).

## Another way

Change the intercept and slope on a fine grid and plot RSS: you see a bowl with its lowest point at the least-squares line.
