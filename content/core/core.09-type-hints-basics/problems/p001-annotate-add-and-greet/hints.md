## Hint 1

Which words of the table tell you the type? "whole number" is `int`, "decimal number" is `float`, "text" is `str`, and `True` or `False` is `bool`. Where do the hints go: after the parameter name, or after the parentheses?

## Hint 2

Parameter hints use a colon: `name: str`. The return hint uses an arrow after the closing parenthesis: `-> str`. Each parameter gets its own hint.
