## Hint 1

Write the string out with its indices underneath: c=0, o=1, m=2, p=3, u=4, t=5, e=6, r=7. Then also write -8 to -1.

## Hint 2

The start is included and the stop is excluded. A slice that runs past the end is trimmed silently.

## Hint 3

`s[-5:-2]` is the same as `s[3:6]`, because the length is 8. `s[4:4]` is empty.
