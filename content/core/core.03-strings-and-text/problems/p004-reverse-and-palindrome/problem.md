# Reverse a line

Read one line of text. Print it **reversed** on the first line, and on the second line print
`True` if the text reads the same backwards (a palindrome), otherwise `False`.

The check is exact: uppercase and lowercase count as different, and spaces count.

**Example 1**

Input:
```
racecar
```
Output:
```
racecar
True
```

**Example 2**

Input:
```
Hello
```
Output:
```
olleH
False
```

An empty line is a palindrome (its reverse is also empty), so it prints an empty line and then `True`.
