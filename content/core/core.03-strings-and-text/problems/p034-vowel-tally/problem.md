# Vowel tally

Read a line and count each English vowel, ignoring case. Print:

```
a: <n>
e: <n>
i: <n>
o: <n>
u: <n>
total: <sum>
```

Only the plain letters a, e, i, o, u count. Accented letters such as `é` are different characters and are not counted.

**Example**

Input:
```
Education Is Important
```
Output:
```
a: 2
e: 1
i: 3
o: 2
u: 1
total: 9
```
