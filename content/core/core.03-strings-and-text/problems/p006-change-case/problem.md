# Five kinds of case

Read one line and print five lines, in this order:

1. all uppercase
2. all lowercase
3. title case (each word starts with a capital)
4. case swapped
5. case-folded (the form used for case-insensitive comparison)

**Example**

Input:
```
hello WORLD
```
Output:
```
HELLO WORLD
hello world
Hello World
HELLO world
hello world
```

Use the string methods. Do not try to change letters yourself.
