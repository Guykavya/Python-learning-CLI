# First, last and length

Read one line of text (it has at least one character) and print three lines:

```
First: <first character>
Last: <last character>
Length: <number of characters>
```

Use `input()` **without** a prompt message.

**Example**

Input:
```
Python
```
Output:
```
First: P
Last: n
Length: 6
```

The text may contain spaces, accented letters or emoji. An emoji counts as one character.
