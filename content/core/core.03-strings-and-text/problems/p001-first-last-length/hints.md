## Hint 1

Positions start at 0. What is the position of the last character of a 6-character string?

## Hint 2

Negative indices count from the end. `s[-1]` is always the last character, whatever the length.

## Hint 3

```
text = input()
print first: text[0]
print last: text[-1]
print length: len(text)
```
