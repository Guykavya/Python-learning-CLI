# Four ways to show a number

Read a number (it may have decimals). Print four lines:

1. with thousands separators and exactly 2 decimals
2. as a percentage with 1 decimal (so `0.256` shows as `25.6%`)
3. in scientific notation with 3 decimals
4. with a sign always shown and 1 decimal

**Example**

Input:
```
1234567.891
```
Output:
```
1,234,567.89
123456789.1%
1.235e+06
+1234567.9
```
