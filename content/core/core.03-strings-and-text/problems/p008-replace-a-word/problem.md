# Replace a word

Read three lines: a sentence, a word to find, and a word to put in its place.
Print the new sentence, then how many replacements were made.

```
<new sentence>
Replacements: <n>
```

**Example**

Input:
```
one fish two fish
fish
cat
```
Output:
```
one cat two cat
Replacements: 2
```

Matching is case-sensitive, just like `replace()`. Every occurrence is replaced, even inside other words.
