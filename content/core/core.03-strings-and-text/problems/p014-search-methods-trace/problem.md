# Search methods

Predict **exactly** what this program prints, one line per `print`. Do not run it until you have written your answer.

```python
s = "hello world"
print(s.find("o"))
print(s.rfind("o"))
print(s.find("z"))
print(s.count("l"))
print(s.index("world"))
print(s.replace("l", "L", 2))
print(s.startswith("hell"))
print(s.endswith("World"))
print("lo w" in s)
print(s.upper().find("O", 5))
```
