# Character codes

Read a single character. Print three lines:

```
Code point: <the number from ord()>
Unicode: U+<the number in uppercase hex, at least 4 digits>
Next: <the character with the next code point>
```

**Example**

Input:
```
A
```
Output:
```
Code point: 65
Unicode: U+0041
Next: B
```

Emoji work the same way: `🙂` is code point 128578, written `U+1F642`.
