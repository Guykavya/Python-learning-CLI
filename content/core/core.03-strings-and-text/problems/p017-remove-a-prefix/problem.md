# Clean a hashtag

Read a hashtag. Print two lines that show the difference between two methods:

```
Once: <the tag with ONE leading # removed, if there is one>
All: <the tag with EVERY leading # removed>
```

**Example**

Input:
```
##python
```
Output:
```
Once: #python
All: python
```

A tag with no `#` is printed unchanged on both lines. A tag that is only `#` becomes empty.
