# The is methods

Predict **exactly** what this program prints, one line per `print`. Do not run it until you have written your answer.

```python
print("2026".isdigit())
print("-5".isdigit())
print("3.14".isdecimal())
print("".isalpha())
print("café".isalpha())
print("hello world".isalpha())
print("abc123".isalnum())
print(" \t\n".isspace())
print("HELLO 2".isupper())
print("Hello World".istitle())
print("²".isdigit(), "²".isdecimal())
print("_name".isidentifier())
```

Write your answer in `answer.txt`, one line per printed line.
