# Slicing edge cases

Predict **exactly** what this program prints, one line per `print`. Do not run it until you have written your answer.

```python
s = "abcdef"
print(repr(s[10:]))
print(s[-10:2])
print(repr(s[4:1]))
print(s[4:1:-1])
print(s[::-2])
print(s[-2::-2])
print(repr(s[1:4:-1]))
print(s[:2] + s[2:])
print(s[::-1][1:3])
print(len(s[::3]))
```

Write your answer in `answer.txt`, one line per printed line.
