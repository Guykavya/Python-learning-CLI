## Approach

Define the two words first, then explain with the position idea: an iterator is one running pass with a bookmark that only moves forward. An iterable is the thing that can hand out a fresh pass.

## Another way

Say it with a book: a list is a book (you can read it many times); an iterator is a finger moving along the page (it only moves forward and it cannot go back).
