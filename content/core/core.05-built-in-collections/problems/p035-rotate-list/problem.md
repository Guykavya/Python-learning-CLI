# Rotate a list

Read a line of items, then an integer `k`. Rotate the list **right** by `k` places: each item
moves `k` places to the right, and items that fall off the end come back at the front. A
negative `k` rotates left. `k` can be larger than the list.

Print the rotated items separated by spaces, or `(empty)` for an empty list.

**Example**

Input:
```
a b c d e
2
```
Output:
```
d e a b c
```
