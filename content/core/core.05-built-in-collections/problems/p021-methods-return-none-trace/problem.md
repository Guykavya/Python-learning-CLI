# What do list methods return?

Predict **exactly** what this program prints, one line per printed line. Do not run it.

```python
a = [3, 1, 2]
b = a.append(5)
print(b)
print(a)
print(a.pop(), a)
print(sorted(a), a)
c = a.sort()
print(c, a)
print(a.extend([4]))
print(len(a), a.index(4))
a = a.reverse()
print(a)
```
