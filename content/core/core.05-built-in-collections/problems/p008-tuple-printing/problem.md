# How tuples print

Read one line of at least one integer. Print three tuples, exactly as Python shows them:

1. all the numbers, as a tuple
2. the tuple `(smallest, largest)`
3. the even numbers, as a tuple

**Example**

Input:
```
3 8 1 6
```
Output:
```
(3, 8, 1, 6)
(1, 8)
(8, 6)
```

Look closely at how Python prints a tuple with **one** item, and a tuple with **no** items.
Your program should let `print` do the work, so it gets these right automatically.
