## Hint 1

`tuple(some_list)` turns a list into a tuple. `print` shows a tuple with round brackets.

## Hint 2

`(min(nums), max(nums))` is a two-item tuple. `tuple(n for n in nums if n % 2 == 0)` is the evens.

## Hint 3

A one-item tuple prints as `(5,)` and the empty tuple prints as `()`. If you build the text by
hand you will probably get these wrong; just `print` the tuple.
