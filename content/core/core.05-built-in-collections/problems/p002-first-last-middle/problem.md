# First, last and middle

Read one line containing at least one word. Print:

```
First: <first word>
Last: <last word>
Middle: <word at index len(words) // 2>
Reversed: <all words in reverse order, separated by spaces>
```

**Example**

Input:
```
red green blue yellow
```
Output:
```
First: red
Last: yellow
Middle: blue
Reversed: yellow blue green red
```

With four words, `4 // 2` is 2, so the middle word is the one at index 2.
