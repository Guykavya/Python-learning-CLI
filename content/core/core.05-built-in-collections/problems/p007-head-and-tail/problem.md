# Head, middle and tail

Read one line of at least **two** integers. Use **star unpacking**,
`first, *middle, last = nums`, and print:

```
First: <first>
Last: <last>
Middle: <middle numbers separated by spaces, or (none)>
Middle sum: <sum of the middle numbers>
```

**Example**

Input:
```
4 8 15 16 23 42
```
Output:
```
First: 4
Last: 42
Middle: 8 15 16 23
Middle sum: 62
```
