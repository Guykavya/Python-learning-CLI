# Words by length

Read one line of words. Group the **distinct** words by length. Print one line per length,
shortest first:

```
<length>: <words of that length, sorted alphabetically>
```

Words are compared exactly as typed (case-sensitive). Print nothing for an empty line.

**Example**

Input:
```
cat dog to a cat be bird
```
Output:
```
1: a
2: be to
3: cat dog
4: bird
```
