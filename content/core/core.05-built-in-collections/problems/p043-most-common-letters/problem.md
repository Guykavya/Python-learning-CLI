# Most common letters

Read one line of text. Count only the **letters** (use `str.isalpha`), ignoring case. Print the
three most common letters (or fewer if there are fewer distinct letters), most common first,
ties in alphabetical order:

```
<letter>: <count>
```

Print `No letters` if there are none.

**Example**

Input:
```
Hello, World!
```
Output:
```
l: 3
o: 2
d: 1
```

`d`, `e`, `h`, `r` and `w` all appear once; alphabetically `d` comes first.
