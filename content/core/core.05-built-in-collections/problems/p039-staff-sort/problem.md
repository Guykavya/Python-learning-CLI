# Sort staff by three keys

Read `n`, then `n` lines of `name dept salary`. Print the staff sorted by:

1. department, A to Z,
2. then salary, **highest** first,
3. then name, A to Z.

Print each person as `dept name salary`.

**Example**

Input:
```
5
ravi IT 50000
asha HR 45000
meena IT 65000
john HR 45000
zoe IT 50000
```
Output:
```
HR asha 45000
HR john 45000
IT meena 65000
IT ravi 50000
IT zoe 50000
```
