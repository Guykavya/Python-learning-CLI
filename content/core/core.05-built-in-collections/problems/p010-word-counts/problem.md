# Count the words

Read one line of text. Split it into words, make each word lowercase, and count how many
times each word appears. Print one line per distinct word, in the order each word **first
appears**:

```
<word>: <count>
```

If the line has no words, print `No words.`

**Example**

Input:
```
The cat saw the other cat
```
Output:
```
the: 2
cat: 2
saw: 1
other: 1
```
