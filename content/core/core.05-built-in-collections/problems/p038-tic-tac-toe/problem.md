# Tic-tac-toe referee

Read three lines of three characters each: `X`, `O` or `.` (empty). Print:

- `X wins` or `O wins` if that player has three in a row (a row, a column or a diagonal),
- `Draw` if the board is full and nobody has won,
- `Game on` otherwise.

You may assume at most one player has a winning line.

**Example**

Input:
```
XO.
OX.
..X
```
Output:
```
X wins
```
