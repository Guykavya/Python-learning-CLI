# Trace range values

Predict **exactly** what this program prints. Do not run it.

```python
print(list(range(4)))
print(list(range(3, 8, 2)))
print(list(range(8, 3, -2)))
print(list(range(5, 5)))
print(list(range(-3, 0)))
print(list(range(0, -3)))
print(len(range(1, 11)))
print(len(range(0, 10, 3)))
total = 0
for i in range(1, 6, 2):
    total += i
print(total, i)
for i in range(10, 0, -4):
    print(i, end=" ")
print()
```

Write your answer in `answer.txt`, one printed line per line.
