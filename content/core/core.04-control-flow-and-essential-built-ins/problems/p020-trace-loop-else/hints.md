## Hint 1

A loop's `else` runs when the loop ends **without** `break`. That includes a loop that runs zero times.

## Hint 2

`continue` is not `break`. It skips the rest of one iteration only.

## Hint 3

Trace `n` in the last loop: 10, then 6, then 2, then...? Is the condition checked before or
after the `if n < 0` test?
