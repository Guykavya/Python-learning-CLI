# Grade bands

Read a whole-number mark and print its grade:

| Mark | Grade |
|---|---|
| 90 to 100 | `A` |
| 75 to 89 | `B` |
| 60 to 74 | `C` |
| 40 to 59 | `D` |
| 0 to 39 | `F` |

A mark below 0 or above 100 is not a real mark. Print `invalid` for it.

Use `input()` without a prompt.

**Examples**

| Input | Output |
|---|---|
| `82` | `B` |
| `40` | `D` |
| `101` | `invalid` |

Try to write each condition with only **one** comparison (except the validity check), by putting the branches in the right order.
