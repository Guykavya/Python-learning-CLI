# First vowel position

Read one word. Find the **first** vowel (`a`, `e`, `i`, `o`, `u`, in small or capital letters).

- If there is one, print `First vowel 'X' at position N`, where `X` is the character as it
  appears in the word and `N` counts from 0.
- If there is none, print `No vowels`.

**Examples**

| Input | Output |
|---|---|
| `rhythm` | `No vowels` |
| `strength` | `First vowel 'e' at position 3` |
| `Apple` | `First vowel 'A' at position 0` |

Stop looking as soon as you find the first one.
