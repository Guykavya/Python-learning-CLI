# Count either way

Read two whole numbers `a` and `b`. Print every whole number from `a` to `b`
**inclusive**, on one line, separated by spaces. If `a` is bigger than `b`, count down.

**Examples**

| Input | Output |
|---|---|
| `3`, `7` | `3 4 5 6 7` |
| `7`, `3` | `7 6 5 4 3` |
| `4`, `4` | `4` |

Use a single `range` with the right step. Do not write two separate loops.
