# Coordinate grid

Read the number of rows `R` and columns `C` (whole numbers, 0 or more). Print a grid of
coordinates: `R` lines, each with `C` cells written `(row,col)`, separated by single spaces.
Rows and columns count from 1.

If `R` or `C` is 0, print `(empty grid)` instead.

**Example**

Input `2`, `3`. Output:

```
(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
```
