# Report the types

`starter.py` defines five variables. Print the **type** of each one, one per
line, in this order: `count`, `price`, `label`, `is_ready`, `nothing`.

Use `type()`. Do not type the answers as text: the tests check that you call
`type` five times.

Before you run it, predict each line. Then compare.

**Example output (format)**

```
<class 'int'>
...
```
