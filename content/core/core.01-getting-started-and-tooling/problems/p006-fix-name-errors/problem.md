# Fix the name errors

`starter.py` should print:

```
Course: BCA
Semester: 1
College: City College
```

It crashes with a `NameError`. Run it, read the last line of the traceback and
the line number, fix that mistake, and repeat.

Rules: keep the three variables, and print their **values through the
variables**. Do not type `BCA` or `City College` into the `print` calls.

**Example**

Output after fixing:
```
Course: BCA
Semester: 1
College: City College
```
