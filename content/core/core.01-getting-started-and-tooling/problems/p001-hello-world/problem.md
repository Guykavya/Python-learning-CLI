# Hello, World!

Your first program. Write a script that prints exactly these two lines:

```
Hello, World!
I am learning Python.
```

Every character matters: capital letters, the comma, the space, the `!` and the
full stop.

Run it from the terminal inside your problem folder:

```bash
$ python3 solution.py
Hello, World!
I am learning Python.
```

**Example**

Input: none.

Output:
```
Hello, World!
I am learning Python.
```
