# A walk through the terminal

Asha's home folder is `/home/asha`. She types these commands one after another
in bash. Predict **everything the terminal prints**, in order. Commands that
print nothing contribute no lines.

```bash
$ cd /home/asha
$ pwd
$ mkdir projects
$ cd projects
$ pwd
$ cd ..
$ pwd
$ cd ~/projects/../projects
$ pwd
$ echo "print('hi')" > hello.py
$ cat hello.py
$ python3 hello.py
$ echo hello | wc -c
```

Write your answer in `answer.txt`, one output line per line.

**Example of the format**

For `cd /tmp` then `pwd`, the answer would be one line: `/tmp`.
