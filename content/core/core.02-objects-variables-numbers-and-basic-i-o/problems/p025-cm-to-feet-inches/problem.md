# Centimetres to feet and inches

Read a height in centimetres (decimals allowed, never negative). Convert it to inches
(1 inch = 2.54 cm), round to the nearest whole inch with `round()`, then split it into feet
and inches (1 foot = 12 inches). Print:

```
<feet> ft <inches> in
```

**Example**

Input:
```
175
```
Output:
```
5 ft 9 in
```

175 cm is 68.897... inches, which rounds to 69 inches, which is 5 feet and 9 inches.
