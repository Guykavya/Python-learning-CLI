# Count positives without if

Read three whole numbers. Print two lines:

1. how many of them are greater than zero
2. how many of them are exactly zero

You have not learned `if` yet, and you do not need it. In Python, `True` behaves like `1`
and `False` behaves like `0` in arithmetic.

**Example**

Input:
```
5
-2
0
```
Output:
```
1
1
```
