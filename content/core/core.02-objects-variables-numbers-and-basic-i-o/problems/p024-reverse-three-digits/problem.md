# Reverse a three-digit number

Read a whole number from 100 to 999. Print two lines:

1. the number with its digits reversed, as a number (so `120` gives `21`, not `021`)
2. the absolute difference between the original and the reversed number

**Rule:** use arithmetic only. No strings.

**Example**

Input:
```
123
```
Output:
```
321
198
```
