# Truthy or falsy

Predict **exactly** what this program prints, one line per `print`. Do not run it.

```python
print(bool(0))
print(bool(-1))
print(bool(0.0))
print(bool(0.1))
print(bool(""))
print(bool(" "))
print(bool("0"))
print(bool("False"))
print(bool(None))
print(bool(0j))
print(0 or 7)
print(3 and "yes")
print(None or 0.0)
```

Write your answer in `answer.txt`, one line per print.
