# Powers of two, exactly

Read a whole number `n` (0 or more, up to a few thousand). Print two lines:

1. `2` to the power `n`, **exactly**, with every digit
2. the last three digits of that number, as a number (so `1024` gives `24`)

**Example**

Input:
```
10
```
Output:
```
1024
24
```

**Example 2**

Input:
```
100
```
Output:
```
1267650600228229401496703205376
376
```
