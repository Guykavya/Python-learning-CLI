# Marks report with booleans

Read marks obtained and maximum marks (both whole numbers, maximum is positive). Print:

```
Percentage: <percentage with 2 decimals>
Passed: <True if percentage is at least 40>
Distinction: <True if percentage is from 75 to 100, inclusive>
Valid: <True if marks are from 0 to the maximum, inclusive>
```

Use chained comparisons such as `75 <= pct <= 100`.

**Example**

Input:
```
78
100
```
Output:
```
Percentage: 78.00
Passed: True
Distinction: True
Valid: True
```
