# Seconds to clock time

Read a whole number of seconds (0 or more) and print it as `H:MM:SS`.

- Hours are not padded and may go above 23.
- Minutes and seconds always have two digits.

Use `input()` without a prompt message.

| Input | Output |
|---|---|
| `0` | `0:00:00` |
| `75` | `0:01:15` |
| `3661` | `1:01:01` |
| `90000` | `25:00:00` |

Do not use the `datetime` or `time` modules. The point is to practise `//` and `%`.
