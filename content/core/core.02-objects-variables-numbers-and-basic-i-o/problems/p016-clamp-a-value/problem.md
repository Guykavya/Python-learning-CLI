# Clamp a value into a range

Read three whole numbers: `value`, `low` and `high` (you may assume `low <= high`).
Print `value` "clamped" into the range: if it is below `low` print `low`, if it is above
`high` print `high`, otherwise print `value` itself.

Do it in one expression with `min()` and `max()`.

**Example**

Input:
```
15
0
10
```
Output:
```
10
```
