# Swap two values

Read two whole numbers into the names `a` and `b` (first line goes to `a`).
Swap them so that `a` refers to the second number and `b` refers to the first.
Then print:

```
a = <a>
b = <b>
```

**Rule:** do not create any other variable. Only the names `a` and `b` may be assigned in your program.

**Example**

Input:
```
4
9
```
Output:
```
a = 9
b = 4
```
