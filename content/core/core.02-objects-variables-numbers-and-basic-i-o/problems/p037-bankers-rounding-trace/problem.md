# Banker's rounding

Predict **exactly** what this program prints, one line per `print`. Do not run it.

```python
print(round(0.5))
print(round(1.5))
print(round(2.5))
print(round(-2.5))
print(round(3.5))
print(round(2.675, 2))
print(round(0.125, 2))
print(round(1234, -2))
print(round(1250, -2))
print(round(7.6))
print(round(7.6, 0))
print(int(7.6))
print(int(-7.6))
```
