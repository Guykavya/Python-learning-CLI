# Distance between two points

Read four numbers `x1`, `y1`, `x2`, `y2` (decimals and negatives allowed). Print:

```
Straight line: <Euclidean distance, 3 decimals>
City blocks: <Manhattan distance, 3 decimals>
```

- Euclidean distance: `sqrt((x2 - x1)**2 + (y2 - y1)**2)`
- Manhattan distance: `|x2 - x1| + |y2 - y1|`

**Example**

Input:
```
0
0
3
4
```
Output:
```
Straight line: 5.000
City blocks: 7.000
```
