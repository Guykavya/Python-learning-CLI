# Augmented assignment step by step

Read a whole number `n`. Apply these steps in order, printing `n` after each one:

1. add 5
2. multiply by 3
3. floor-divide by 2
4. subtract 1
5. square it (power 2)
6. take the remainder after dividing by 7

Use augmented assignment operators (`+=`, `*=`, `//=`, `-=`, `**=`, `%=`).

**Example**

Input:
```
1
```
Output:
```
6
18
9
8
64
1
```
