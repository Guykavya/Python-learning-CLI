# Scale a recipe exactly

A recipe needs an amount of flour written as a fraction of a cup, like `3/4`. Read:

1. the amount, as a fraction or whole number (`3/4`, `2`, `1/3`)
2. the number of servings the recipe makes
3. the number of servings you want

Print:

```
Cups: <scaled amount as an exact fraction>
About: <scaled amount as a decimal with 3 places>
```

**Example**

Input:
```
3/4
4
6
```
Output:
```
Cups: 9/8
About: 1.125
```
