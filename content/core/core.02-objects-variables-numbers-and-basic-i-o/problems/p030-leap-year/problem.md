# Leap year as a bool expression

Read a year (a positive whole number). Print `True` if it is a leap year, otherwise `False`.

The Gregorian rule:

- a year divisible by 4 is a leap year,
- **except** a year divisible by 100 is not,
- **except** a year divisible by 400 is.

Write it as one bool expression with `and`, `or` and `%`.

**Example**

Input:
```
2024
```
Output:
```
True
```
