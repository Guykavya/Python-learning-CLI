## Hint 1

When a `print` call has `end` set to something without a newline, where does the next `print` start?

## Hint 2

`sep` goes **between** items. `sep="\n"` puts a newline between items, so one call can print two lines.

## Hint 3

`sep` is used exactly as given. `"total:"` already ends with a colon; `sep=" = "` adds space, equals, space.
