# print() layout

Predict **exactly** what this program prints. Pay attention to spaces and to where lines break.
Do not run it.

```python
print(1, 2, 3)
print(1, 2, 3, sep="")
print("a", "b", sep="--", end="|")
print("c")
print("x", end="")
print("y", "z", sep=",")
print(10, 20, sep="\n")
print("total:", 5 + 5, sep=" = ")
print("A", "B", "C", sep="", end="!\n")
```

Write your answer in `answer.txt`, one line per printed line.
