# Sum of the digits

Read a whole number between -9999 and 9999. Print two lines:

1. the sum of its digits (ignore the minus sign)
2. `True` if the number is divisible by 3, else `False`, worked out from the digit sum

You have not learned loops, but a number has at most four digits here, so four steps are enough.

**Rule:** use arithmetic (`//`, `%`, `abs`). Do not convert the number to a string.

**Example**

Input:
```
-4071
```
Output:
```
12
True
```
