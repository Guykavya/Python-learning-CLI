# Three kinds of division

Read two whole numbers `a` and `b` (`b` is never 0; either may be negative). Print four lines:

1. `a / b`
2. `a // b`
3. `a % b`
4. `divmod(a, b)`

Print each result directly with `print(...)`, no formatting.

**Example**

Input:
```
-7
2
```
Output:
```
-3.5
-4
1
(-4, 1)
```
