# Rectangle calculator

Write a program that reads the **width** and then the **height** of a rectangle
(each on its own line, may contain decimals) and prints:

```
Area: <area>
Perimeter: <perimeter>
```

Both numbers must be shown with exactly **2 decimal places**.

Use `input()` **without** a prompt message (just `input()`), so the checker can read your output cleanly.

**Example**

Input:
```
3
4.5
```
Output:
```
Area: 13.50
Perimeter: 15.00
```
