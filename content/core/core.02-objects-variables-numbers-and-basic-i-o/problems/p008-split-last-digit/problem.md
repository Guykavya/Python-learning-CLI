# Peel off the last digit

Read a non-negative whole number `n`. Print three lines:

1. its last digit
2. the number left after removing the last digit
3. its second-to-last digit (0 if there is none)

**Rule:** use arithmetic only (`//` and `%`). Do not convert the number to a string.

**Example**

Input:
```
1234
```
Output:
```
4
123
3
```

**Example 2**

Input:
```
7
```
Output:
```
7
0
0
```
