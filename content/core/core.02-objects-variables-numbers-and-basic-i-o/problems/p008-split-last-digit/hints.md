## Hint 1

What is the remainder when 1234 is divided by 10? What is the whole-number quotient?

## Hint 2

`n % 10` is the last digit. `n // 10` drops the last digit.

## Hint 3

The second-to-last digit is the last digit of `n // 10`, so `n // 10 % 10`.
`//` and `%` have the same precedence and go left to right.
