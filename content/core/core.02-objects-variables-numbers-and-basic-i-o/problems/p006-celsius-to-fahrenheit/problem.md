# Celsius to Fahrenheit and Kelvin

Read a temperature in degrees Celsius (it may have decimals and may be negative). Print:

```
F: <fahrenheit with 1 decimal place>
K: <kelvin with 2 decimal places>
```

Formulas: `F = C * 9 / 5 + 32` and `K = C + 273.15`.

**Example**

Input:
```
100
```
Output:
```
F: 212.0
K: 373.15
```

**Example 2**

Input:
```
-40
```
Output:
```
F: -40.0
K: 233.15
```
