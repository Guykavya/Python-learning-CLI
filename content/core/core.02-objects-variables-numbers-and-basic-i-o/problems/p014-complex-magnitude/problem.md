# Complex number basics

Read two numbers: the real part and the imaginary part of a complex number `z`.
Print three lines:

1. `z` itself, printed directly
2. `|z| = <magnitude with 3 decimals>`
3. the conjugate of `z`, printed directly

**Example**

Input:
```
3
4
```
Output:
```
(3+4j)
|z| = 5.000
(3-4j)
```
