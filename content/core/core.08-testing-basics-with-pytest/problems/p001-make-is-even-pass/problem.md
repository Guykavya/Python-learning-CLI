# Make the failing tests pass: is_even

This is your first test-driven exercise. The **tests are the specification**: read
`test_solution.py` (open it from the problem folder, or run `./learn check` and read the report)
and write the function so they all pass.

`starter.py` contains an `is_even(n)` that is wrong. Run the tests, read the failure report
(chapter sections 4 and 5), find the bug and fix it.

**Examples**

```python
is_even(4)    # True
is_even(7)    # False
is_even(0)    # True
is_even(-3)   # False
```

Return a real `True` or `False`, not `1` or `0`.
