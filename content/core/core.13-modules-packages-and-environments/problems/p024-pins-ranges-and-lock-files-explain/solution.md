## Approach

Separate two questions: "which versions *can* my code work with?" (ranges, declared in
`pyproject.toml`) and "which versions *did* we test and deploy?" (a lock file, generated by a tool). A
library answers only the first; an application needs both.

## Another way

Try it in a fresh virtual environment: `pip install flask`, then `pip freeze`. Count how many
packages appear although you asked for one. Each of them is a transitive dependency that a lock
file would pin. With uv, compare `pyproject.toml` with the `uv.lock` that `uv add flask` writes.
