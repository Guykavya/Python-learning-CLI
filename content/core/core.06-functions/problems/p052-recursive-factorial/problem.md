# Factorial by recursion

Write `factorial(n)` **recursively** (the function calls itself; no loops). For `n >= 0`:

- `factorial(0)` is `1`;
- otherwise `factorial(n)` is `n * factorial(n - 1)`.

**Examples**

```python
factorial(5)    # 120
factorial(0)    # 1
factorial(1)    # 1
factorial(20)   # 2432902008176640000
```
