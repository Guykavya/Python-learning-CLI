# Product with functools.reduce

Write `product(numbers)` that returns the product of all the numbers, using `functools.reduce`.
The product of an empty list is `1` (just as the sum of an empty list is `0`).

**Examples**

```python
product([3, 5, 2, 4])   # 120
product([7])            # 7
product([])             # 1
product([2, -3])        # -6
```
