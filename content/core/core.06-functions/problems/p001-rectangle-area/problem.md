# Rectangle area with a docstring

Write a function `rectangle_area(width, height)` that **returns** the area of a rectangle.

Give it a **docstring**: a one-line summary such as
`"""Return the area of a width x height rectangle."""` as the first statement of the body.

The function must not print anything. The tests call it and check the value it gives back.

**Examples**

```python
rectangle_area(3, 4)      # returns 12
rectangle_area(2.5, 2)    # returns 5.0
rectangle_area(0, 7)      # returns 0
```
