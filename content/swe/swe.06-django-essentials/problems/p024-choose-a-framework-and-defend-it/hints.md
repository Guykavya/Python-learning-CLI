## Hint 1

Take one job at a time and answer the five questions of section 19.2 in one short line each: who is the user, is the data model the heart, is the work mostly waiting, how much do you want to decide yourself, how long will it live. Which framework do the answers point to?

## Hint 2

A defence has four parts (section 19.4): the job, the choice with reasons tied to the job, the **cost** you accept, and the **trigger** to revisit. Most weak answers forget the cost and the trigger. Ask yourself: what do I give up with this choice, and what measurement would change my mind?

## Hint 3

```text
B  user is a program, mostly waiting, no admin        -> async API framework; cost: build auth and data screens yourself
D  people + staff, data model central, permissions    -> batteries included; cost: heavier, async not the strength
G  working Django code exists, one new live feature   -> keep it, add a small piece; cost: two parts to run
each: choice + reason tied to job + cost + trigger
```
